# C 语言练习

这是一个 C 语言基础程序集合，涵盖算术、条件判断、循环、字符串、数组和基础算法。

> 课程说明：本目录收录课程实验或课程作业的解决方案。

## 主题

- 方程计算、球体体积与成绩等级
- 素数与利息计算
- 字符大小写转换与逆序输出
- 选择排序与投票统计

## 编译运行

使用 GCC 等 C 编译器分别编译每个练习：

```powershell
gcc -std=c17 -Wall -Wextra -o prime Prime_Numbers.c
.\prime.exe
```

每个源文件都有独立的 `main` 函数，应单独编译运行。
