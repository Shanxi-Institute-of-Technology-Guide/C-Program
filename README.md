# C Programming Exercises

A collection of introductory C programs covering arithmetic, conditions, loops, strings, arrays, and basic algorithms.

> Academic context: this directory contains course lab or coursework solutions.

## Topics

- Equation calculation, sphere volume, and grade evaluation
- Prime numbers and interest calculation
- Character case conversion and reverse-order output
- Selection sort and voting statistics

## Compile and Run

Compile an individual exercise with a C compiler such as GCC:

```powershell
gcc -std=c17 -Wall -Wextra -o prime Prime_Numbers.c
.\prime.exe
```

Each source file has its own `main` function and should be compiled separately.
